
# Contributing Guidelines

Thank you for considering contributing to this project!

## 🏷️ Branch Naming Conventions

To keep our repository organized and consistent, please follow these branch naming guidelines:

### ✏️ Format
```
[type]/[short-description]
```

### 🔧 Allowed Types
- `feat/` – New features
- `fix/` – Bug fixes
- `chore/` – Maintenance or non-functional changes
- `docs/` – Documentation updates
- `test/` – Adding or updating tests
- `refactor/` – Code changes that neither fix a bug nor add a feature
- `ci/` – Continuous Integration related changes

### 📌 Examples
```
feat/user-authentication
fix/login-redirect
docs/update-readme
refactor/form-validation
```

Please make sure to follow this convention when creating a new branch.
